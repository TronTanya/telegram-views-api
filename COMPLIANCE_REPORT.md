## ✅ Выполненные требования

### 1. REST API endpoint
- **Статус**: реализовано
- **Файл**: `api.py`
- **Endpoint**: `POST /predict` (основной)
- **Дополнительно**: `POST /predict_batch` (массовый, разрешено как улучшение)

### 2. Формат входных данных
- **Статус**: соответствует
- **Формат**:
```json
{"cpm": float, "channel": str, "date": "YYYY-MM-DD"}
```
- Реализована валидация обязательных полей, формата даты, положительности CPM.

### 3. Формат выходных данных
- **Статус**: соответствует (строго)
- **Формат**:
```json
{"predicted_views": int}
```

### 4. Модель машинного обучения
- **Тип**: регрессия (CatBoost)
- **Цель**: `VIEWS`
- **Входные признаки**: CPM, CHANNEL_NAME, DATE (как требуется)
- **Метрики**: MAE, RMSE, R² (в `model_metrics.txt`)

### 5. Обработка тестового датасета
- **Требование**: заполнить `VIEWS` в тестовом CSV
- **Реализация**: `predict_test_dataset.py`
- **Результат**: `TestDataset_predictions.csv`

### 6. Документация
- **README.md**: присутствует с инструкциями
- **requirements.txt**: присутствует
- **Скриншоты**: в папке `scr/`

### 7. Технологии
- **Язык**: Python 3.10+ (фактически 3.11.9)
- **Библиотеки**: pandas, numpy, scikit‑learn, xgboost, lightgbm, catboost
